# Full workspace backup

These two zip files hold the complete working directory from the analysis sessions (made 10 Nov 2026), so that nothing is lost if the temporary session workspace is wiped.

| File | What's inside |
|---|---|
| `workspace_part1_data_trees_scripts.zip` | Every sequence file, alignment, tree, IQ-TREE report, log, script and JSON table from the analysis (about 1,000 files). |
| `workspace_part2_ancestral_state_tables.zip` | The 13 full ancestral-state tables (`.state` files) from IQ-TREE. They are large and only needed to re-check a reconstruction at a new position. |
| `workspace_part3_euglena_trees.zip` | Round 3 (10 Nov): *Euglena gracilis* added to both trees: alignments, trees, constrained searches, AU tests, `.state` files and scripts (under `audit/euglena_trees/`). |
| `workspace_part4_round4.zip` | Round 4 (10 Nov): every BLAST hit parsed from `3_data/blast_results`, the 245-sequence spermidine synthase and 200-enzyme AdoMetDC trees, constrained searches, AU tests, `.state` files and scripts (under `audit/round4/`). |
| `workspace_part5_docking.zip` | Putrescine docking (10 Nov): the AlphaFold models superimposed on 1MSV, receptor/ligand files, every Vina and AutoDock4 pose and log, summary JSON and scripts (files at the zip's top level, scripts in `scripts_copy/`). AutoDock4 grid maps are left out (rebuild with `autogrid4`). |

**Left out on purpose:** IQ-TREE checkpoint/distance files (regenerated by rerunning), extracted paper text (copyright), and corrected copies of Marc's project reports (those belong in his repository).

**To use:** download a zip and double-click it to unzip. Everything sits under an `audit/` folder:

- `audit/strameno/`: main Glu178 analysis (`expand/` = 187-enzyme tree; `expand2/` = robustness round 2 and ancestral reconstruction)
- `audit/spdsyn/`: spermidine synthase tree
- `audit/euglena/`: *Euglena* sequences from BLAST searches G and H
- `audit/bodo/`, `audit/dhs*/`, `audit/full/`: *Bodo* prozyme side thread
- `audit/novelty/`: literature-search tables
