# p21 E: p12 interface residues regenerated

`results/p12_interface_residues.tsv` was regenerated by rerunning `scripts/p12_interface_vs_catalytic.py --smoke`
with the Lys69 fix (1D7K stores Lys69 as LLP, a HETATM; `protein_only()` now keeps it as lysine atoms and drops the
PLP atoms). All five p12 files on disk were from the 20 Nov smoke run (our 23 only), and the full p12 run has
never been done, so the same smoke run was repeated; the full run (baselines) is still outstanding.

## What changed

- `p12_interface_residues.tsv`: one row added, ODC position 69 (K; buried surface 76.2 A2; 3.31 A from the partner
  chain; contact at 4.0, 4.5 and 5.0 A; catalytic). No other residue changed its contact flag. Buried-surface values
  of K69's neighbours changed because the lysine side chain is now present (70, 90, 94, 360, 361, 389, 392, 397,
  398), and residue 397's minimum distance to the partner fell from 3.77 to 3.31 A.
- `p12_report.md`, interface table only: ODC buried surface 5,095 -> 5,304 A2; interface residues at 4.0 / 4.5 / 5.0 A
  61 / 70 / 79 -> 62 / 71 / 80; catalytic-and-interface overlap Y331, C360, D361, Y389 -> **K69**, Y331, C360, D361,
  Y389; "70 mappable contact residues" -> 71.

## What did not change

- The interface-only set (interface minus the 13 catalytic positions) is the same 66 residues before and after,
  because K69 is catalytic and overlap residues count as catalytic only.
- Therefore `p12_odc_per_protein.tsv`, `p12_adometdc_per_protein.tsv` and `p12_tests.tsv` are byte-for-byte
  unchanged, and the p12 conclusions stand.
- **p20 does not change.** Its sets are (i) interface minus catalytic, (ii) catalytic, (iii) everything else; K69
  was already in (ii), and set (i) is the same 66 positions. p20 was not rerun.
